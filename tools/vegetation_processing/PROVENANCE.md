## Geometry

Tree geometry is generated by the Blender Python script using:
- Tapered cylinder trunk with slight organic lean
- Branch system (LOD0/LOD1 only)
- Alpha card foliage (crossing textured quads with alpha cutoff)

This is NOT derived from the previous Rust procedural builders (puff_blob, tube_sweep, frond_mesh).

## Regenerating Assets

```bash
# 1. Download textures (see URLs above) into textures/<asset_name>/
# 2. Run Blender in background mode:
blender --background --python generate_production_trees.py
# 3. Output goes to crates/renderer/assets/vegetation/
```
